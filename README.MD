# ☕ Site da Cafeteria

Bem-vindo ao projeto do site da nossa cafeteria!

Este projeto tem como objetivo criar uma presença digital moderna, acolhedora e intuitiva para uma cafeteria, permitindo que os clientes conheçam o espaço, o cardápio e os produtos oferecidos.

## 🌱 Sobre o projeto

O site apresenta a cafeteria e oferece aos visitantes informações sobre:

- ☕ Cafés e bebidas
- 🥐 Doces e acompanhamentos
- 🍰 Produtos disponíveis
- 📍 Localização
- 🕐 Horário de funcionamento
- 📞 Informações de contato
- 📱 Redes sociais

## 🎯 Objetivo

Criar um site simples, elegante e responsivo que represente a identidade da cafeteria e proporcione uma boa experiência aos clientes.

## 🛠️ Tecnologias

O projeto será desenvolvido utilizando:

- HTML5
- CSS3
- JavaScript
